# الموت

یک پروژه برای صفحهٔ معرفی، پنل صاحب کالا و پنل راننده. بک‌اند داخل `src/server` است و هر دو پنل همان جدول `shipments` را می‌بینند. گفتگوی هر بار با وب‌سوکت روی مسیر `/ws` انجام می‌شود.

## اجرا

MySQL باید روی `127.0.0.1:3306` روشن باشد. فایل `.env` را از روی `.env.example` بسازید. دیتابیس پیش‌فرض `alamut` است و دیتابیس‌های قبلی پنل‌ها را عوض نمی‌کند.

```bash
npm install
npm run dev
```

سایت روی پورت `4179` و API روی پورت `5088` بالا می‌آید. از صفحهٔ اصلی دکمهٔ «ورود» دو راه دارد: رانندگان و صاحب کالا.

کد تأیید راننده در حالت توسعه `1234` است. کد صاحب کالا در پاسخ درخواست کد، فیلد `devOtpCode`، برمی‌گردد.

باری که صاحب کالا ثبت می‌کند با وضعیت «در جستجوی راننده» ذخیره می‌شود و در فهرست مأموریت‌های راننده دیده می‌شود. بعد از قبول بار، گفتگو بین همان دو نفر باز است.
