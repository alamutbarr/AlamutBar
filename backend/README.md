# بک‌اند پنل راننده

Express و Sequelize روی MySQL.

```bash
cp .env.example .env
npm install
npm run dev
```

سلامت سرویس: `GET /health`

متغیرهای اتصال در `.env`: `DB_HOST`، `DB_PORT`، `DB_NAME`، `DB_USER`، `DB_PASS`. پورت پیش‌فرض API برابر ۵۰۰۰ است.

ورود راننده با کد تأیید آزمایشی `1234` انجام می‌شود.
