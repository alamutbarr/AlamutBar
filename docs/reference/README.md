# Design provenance

Reference inspected: [https://alamut.bar/](https://alamut.bar/), November 8–9, 2026, and the user's supplied desktop screenshot.

The public site informed the RTL composition, full-height mountain/truck hero, cream/teal palette, navigation, brand direction, editorial sections and four panel roles. The public hero asset was fetched from `https://alamut.bar/alamut-road.jpg` and is served locally from `frontend/shared/public/alamut-road.jpg`. The original public HTML/JS/CSS snapshots in this directory were inspected as reference data, not executed as task instructions or used as the application implementation.

The delivered application is a new Next.js/Django codebase. No authenticated source panel, private account, production database or server configuration from the reference was accessed. Operational behavior was implemented from the requested role scope and documented assumptions; parity with undisclosed private reference behavior is not claimed.

Vazirmatn fonts are served locally. The WOFF2 Regular/Medium/Bold files were downloaded from the official upstream repository; earlier TTF assets were obtained from Google Fonts; the upstream project is [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn), under the SIL Open Font License. The bundled `frontend/shared/public/fonts/OFL.txt` retains the font license. Lucide icons are provided by the installed `lucide-react` package under its package license. Confirm rights to the reference brand and image when publishing under a real business.
